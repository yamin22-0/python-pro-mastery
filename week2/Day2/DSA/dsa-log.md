## Best Route

**Approach:** Handled graph pathfinding or route comparison logic by evaluating destination weights, tracking minimum distances or optimal connections, and returning the most efficient traversal path.

**Key Takeaway:** Breaking down multi-step conditions and keeping track of visited nodes prevents infinite loops and keeps tracking variables clean.

## Running Sum of 1d Array

**Approach:** Iterated through an array while keeping a running total accumulator, updating each position or building a new list where every element is the sum of all preceding elements up to that index.

**Key Takeaway:** Using a simple accumulator variable inside a single loop makes prefix-sum operations run in linear time without needing nested loops.
